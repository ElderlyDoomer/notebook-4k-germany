## Как проверять пункт

- Ищи на idealo.de по модели или парт-номеру (Herstellernummer). Сортировка по цене.
- Бери только новые товары (не B-Ware, не б/у, не «refurbished»), продавцы — нормальные магазины, цена с доставкой.
- Для каждого подходящего SKU запиши: парт-номер, CPU, ОЗУ как указано (и есть ли «aufgerüstet»), SSD, экран (дюймы, разрешение, IPS/OLED, Гц),
  видеокарта, ОС (с Windows / без ОС), минимальная цена с доставкой, магазин, ссылка на карточку, дата.
- Интересны: 32 ГБ + 1 ТБ до 1100 €; 16 ГБ + 1 ТБ до ~800 € (планка 16 ГБ DDR5 сейчас стоит 220–340 €, дороже нет смысла);
  с видеокартой от 8 ГБ — до 1100 €.
- Процессор записывай точно — старые Intel под новыми именами отсеет облачная сессия.
