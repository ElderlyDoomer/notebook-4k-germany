## Пояснения

- **2.2 / REPORT:148.** «Около 150 €» за +16 ГБ и +512 ГБ посчитано по устаревшему «ab 1045,58» (это было 05–09.07.2026). Сейчас 1122 − 899 = 223 €. Вывод не меняется: 223 € меньше, чем одна планка 16 ГБ (244–289 € на geizhals) плюс SSD.
- **2.4 / REPORT №8.** 83V70037GE не продаёт ни один магазин на geizhals с 28.08, на idealo карточки нет. Остаётся только Amazon.de (1049,49 € на 23.08 по notebookcheck) — это другой пункт, я его не проверял. Если Amazon тоже не продаёт, №8 перевести в «нет в продаже».
- **2.8.** geizhals — не источник цен для отчёта (по CLAUDE.md цены берутся с idealo). Здесь только датировка сниппетов: 161 € за ADATA — это декабрь 2025, сейчас минимум среди этих планок 243,90 € (Crucial, alza.de, CZ).
- **2.10 / REPORT:128.** По geizhals 83GW00A9GE = 1×16 + свободный слот, максимум 32 ГБ. Если PSREF подтвердит, V15 G5 + планка 16 ГБ ≈ 599 + 244 ≈ 843 € (по idealo-цене планки — пересчитать).
- **1.23.** Скидки за «без ОС» у Lenovo V15 G5 нет: два SKU с Windows дешевле, чем такие же без ОС. Если Windows нужна, покупка лицензии в магазине (от ~131 € за Home) дороже, чем любая найденная разница.
- **Как снималась история geizhals:** POST `/api/gh0/price_history` с `{"id":[<id>],"params":{"days":9999,"loc":"de"}}` со страницы geizhals. Допустимые `days`: 7, 31, 91, 183, 365, 9999. Ответ `[timestamp, цена, …]`, цена в евро.
