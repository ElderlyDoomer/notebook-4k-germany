## Коротко

1. **Новый кандидат с современным CPU: HP 15-fd1555ng — CU7G6EA.** Core Ultra 5 125H (Meteor Lake-H, iGPU Arc), **1×24 ГБ DDR5-5600 + свободный слот** (по сервис-мануалу HP есть конфигурации 2×16 → слотов два), 1 ТБ, 15,6" FHD IPS 300 нит **62,5 % sRGB**. Стоит **783,17 €**, доставка бесплатная, 15 предложений. С планкой 16 ГБ DDR5-5600 получается **≈ 1020–1027 €** и **40 ГБ (24+16)**. Минусы: HDMI 1.4b (только 1080p60, 4K60 — через USB-C DP 1.4b), 41 Втч, нет RJ45/SD/TB4. **HEVC — неизвестно:** у потребительских HP были случаи отключения без пометки в даташите.
2. **Lenovo V15 G5 — 83GW00A9GE (дополнение):** магазин nullprozentshop.de пишет «Verbaut: 1 von 2» → **1×16 + свободный слот** (не даташит; Icecat — «Zweikanalig» без раскладки). **598,98 €** + планка = **≈ 836–843 €**. CPU i5-13420H (13-е поколение, iGPU UHD) — старый и слабый для 4K.
3. **Новый, DDR4: Wortmann TERRA MOBILE 1516R — 1220844.** i5-1334U (13-е поколение, U, 15 Вт). На странице производителя: **«2 Sockel, 1 x davon frei»**, 16 ГБ DDR4. **818,62 €** + планка DDR4 16 ГБ **113,17 €** = **≈ 932 €**. Есть RJ45, VGA, SD, DVD-RW и отсек SATA 2,5". Весит 2,2 кг; процессор для монтажа 4K слабый.
4. **Acer Aspire Go 15 — NX.JRREG.00B (дополнение):** платформа AG15-72P по даташитам Acer соседних SKU — **DDR4** («Bis zu 32 GB DDR4 RAM (2x 16 GB soDIMM)»). Значит, докупка — DDR4 за ~113 €, итог **≈ 861 €** (а не 950–1020 €). CPU Core 7 150U — ловушка.
5. **Пересчёт 83V70077GE (Lenovo, 1×24 + слот, 135H):** по сегодняшним ценам billiger фирменная 16-ГБ планка DDR5-5600 стоит **236,83–243,90 €**. Итог 871,37 (с доставкой) + 236,83 + БП ~22 = **≈ 1130 €**, то есть **выше потолка**. В 1100 € укладывается только с DDR5-4800 Integral за 193,40 € (≈ 1087 €).
6. Остальные Intel-ноутбуки 15–16" с 16 ГБ и 1 ТБ на billiger.de (377 позиций, все цены) — это 2×8, одна планка без второго слота, LPDDR5x распайка, сборки продавцов или модели без подтверждённой раскладки (таблицы ниже). **Ни одного другого Core Ultra H с 1×16 + слот + 1 ТБ ≤ ~870 € нет.**

## Метод

- billiger.de, категория «Notebooks», фильтры **RAM = 16 ГБ, SSD = 1 ТБ, экран 15–16"**, сортировка по цене — **377 позиций, все цены** ([выдача](https://www.billiger.de/show/kategorie/2303.htm?order=s_price&filter=f_4266_16000000000x16000000000%2Cf_5198_1000000000000x1000000000000%2Cf_162_15x16)). Тот же поиск без фильтра экрана (до ~1000 €) и с **RAM = 24 ГБ** ([выдача](https://www.billiger.de/show/kategorie/2303.htm?order=s_price&filter=f_4266_24000000000x24000000000%2Cf_5198_1000000000000x1000000000000)). Отобраны все Intel-SKU ≤ 1000 € (для DDR4 — до ~1100 €).
- Для каждого SKU: EAN со страницы billiger → Open Icecat по GTIN (парт-номер, «Speicherlayout», слоты, тип памяти). Где Icecat пуст — даташиты: HP datasheet + HP Maintenance & Service Guide, Wortmann, Acer (PDF на gzhls.at), Dell Owner's Manual, medion.com.
- Характеристики billiger (таблица «Produkteigenschaften») ненадёжны: у 83GW00A9GE там указан «Intel Core i5-4210U». Для раскладки их не использовал.
- Не открывал (блок из облака, не обходил): idealo, geizhals, notebooksbilliger, Galaxus, acer.com, msi.com, csl-computer.com (403), captiva-power.de. PSREF API без токена отвечает 404 — Lenovo брал из прошлых проходов.
- HEVC: для HP и Dell — по источникам в тексте; для Lenovo, Wortmann, Acer — прямых данных нет («неизвестно»).
