# Ноутбук на AMD

Подбор ноутбука на AMD Ryzen для монтажа 4K (до 1100 €, Германия) и сравнение с разбором по Intel (`../Intel/`).

- `CLAUDE.md` — правила: задача, критерии, порядок работы.
- `MEMORY.md` — память: что найдено, что отброшено, следующие шаги.
- `REPORT.md` — итоговый отчёт (когда будет готов).
- `notes/` — подробные заметки с источниками.
