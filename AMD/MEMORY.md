## Ответы пользователя (2026-09-30, общие с Intel)

- Ноутбук — для другого человека, он будет на Windows. Сам пользователь — на Arch Linux.
- Бюджет: **1100 € — жёсткий потолок** (с докупкой памяти). Windows в комплекте не нужна.
- Программа монтажа и камера неизвестны. Пользователь считает, что Intel умеет всё то же, что AMD, плюс некоторые форматы аппаратно — проверено, см. «Кодеки».
- Распаянная память — нежелательна, но допустима при хорошей цене. 16 ГБ + докупить планку — да, если заметно дешевле.
- Вес не ограничен. Немецкая раскладка подходит.
- В итоге: у каждого кандидата ссылка на карточку idealo этого P/N; у каждого факта — ссылка на источник; цены — только idealo через Chrome пользователя.
- **Где покупать — неважно, главное цена**: маркетплейсы (Amazon MP, Kaufland, eBay…) и офлайн подходят; цена кандидата = минимальная цена нового товара у любого продавца.
- **Ответы 30.09 (вечер):** кодек камеры и программа монтажа не будут известны никогда — вводная только «4K-видео», выбор должен быть надёжным для любых исходников; покупка — сейчас (варианты «ждать» — только справка); внешнего монитора не будет — экран ноутбука важен; планку/SSD владелец поставит сам — «+ планка» и «+ SSD» полноценные; порты (USB4, Ethernet, SD, HDMI 2.1) — приятный бонус, не требование.
