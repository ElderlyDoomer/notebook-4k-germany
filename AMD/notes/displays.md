## Коротко

1. **Работать с цветом без внешнего монитора по даташиту можно только на одном кандидате — Acer Aspire 16 AI OLED `NX.JP0EG.00Z`** (AMD №8): OLED, 95–100 % DCI-P3.
   Но у него нет ни одного независимого замера, ШИМ не проверен, яркость 300 нит, экран глянцевый.
   Остальные минусы — из отчёта: память распаяна, есть риск с HEVC у Acer.
   Если брать его, проверить экран в пределах срока возврата: мерцание на малой яркости, равномерность, профиль sRGB.
2. **Остальные 25 P/N — бюджетные IPS.** У 21 из них в даташите «45 % NTSC»; Medion `MD600023`, Acer `.005`, `NX.J4GEG.00D` и `NX.JCJEG.00K` охват не указывают; у двух HP — 62,5 % sRGB (п. 3).
   Там, где есть замеры той же или родственной панели, NBC намерил 53–63 % sRGB и 36–42 % DCI-P3; у LaptopMedia для Aspire Go 15 — 50 % sRGB.
   Это примерно половина охвата, нужного для цвета (≥ 95–100 % sRGB): насыщенные цвета будут бледнее, чем их увидит зритель. Для цветокоррекции они не годятся.
3. **HP `BM9T4EA` и `CU7G6EA` заявляют 62,5 % sRGB** и DC dimming — чуть лучше класса «45 % NTSC», но тоже не для цвета. Замеров нет.
4. **Среди IPS лучшие по вторичным параметрам:**
   - самый яркий — ThinkBook 16 G9 AHP (400 нит по даташиту, у родственной панели — 449 нит);
   - высокий контраст — у родственных панелей ExpertBook P1 (1520:1, ΔE 3,69) и E16 (1456:1).
   Охват это не меняет.
5. **Мерцание:** у всех измеренных IPS NBC и LaptopMedia ШИМ не нашли. Для HP заявлен DC dimming. Не проверены только OLED и экраны без замеров.
6. **Вывод для выбора:** при критерии «экран без внешнего монитора» список «купить сейчас» почти не даёт вариантов — годится только Acer OLED, и то с оговорками.
   Ближайший IPS со 100 % sRGB — `22AY004XGE` за 1207,78 €, дороже потолка.
   Имеет смысл отдельно просканировать idealo по SKU ≤ 1100 € с OLED или «100 % sRGB» (этого в задаче не было, не делал).
